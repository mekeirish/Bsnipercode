Guide
À propos de Snipercode
Token = ton compte
Dès que tu colles ton token GitHub, Snipercode récupère automatiquement ton pseudo et te propose la liste de tous tes dépôts.
Autocomplétion repo
Tape les premières lettres du nom du dépôt — la liste se filtre en temps réel. Navigue avec ↑ ↓ et valide avec Entrée.
Charger le projet
Récupère tous les fichiers texte de la racine du dépôt et les affiche sous forme de carreaux colorés classés par type.
Éditeur en modale
Clique sur un carreau pour ouvrir l'éditeur plein écran. Modifie, cherche, remplace, déploie.
Historique
Consulte les 10 derniers commits du fichier et restaure n'importe quelle version.
Update Core
Push le fichier sur GitHub. Le statut du déploiement est suivi en temps réel via GitHub Actions.
Site Live
La LED indique l'état, la barre de progression visualise les 45 secondes de latence GitHub Pages.
Raccourcis
Tab indente · Ctrl/Cmd+S déploie · Entrée valide la recherche · Échap ferme
